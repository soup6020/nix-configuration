* Basics
This is my NixOS/nix-darwin configuration. It is not the prettiest you'll ever see, but it works for me. I am specifically avoiding home-manager for the sake of eval times.

One of my flake outputs builds a live iso, this uses hjem to copy some dotfiles into place.

* Directories explained
~hosts/~: Configurations for individual machines. Most of the things in here are either deployment specific, or trivial enough I don't feel like splitting them into a module.

~hosts/<name>/hardware.nix~: Hardware configuration, largely automatically generated.

~modules/shared~: Modules that must evaluate on both NixOS and nix-darwin. Platform-specific options belong in ~modules/nixos~ or ~modules/darwin~.

~modules/nixos~: NixOS-specific modules, including the NixOS-only halves of ~modules/shared~.

~modules/nixos/containers~: Podman containers (via quadlet-nix) and the Caddy reverse proxy in front of them.

~modules/nixos/svc~: Modules that define and configure services. Trivial service definitions are generally left inside host configurations.

~modules/nixos/sys~: Modules that demand system level functionality changes. Invasive or resource-intensive services may be found here, as well as lower level configuration changes.

~modules/nixos/desktop~: Graphical, desktop-oriented functionality.

~modules/nixos/dev~: Development environment tweaks.

~modules/nixos/pkgs~: Some nonsense I have yet to organize into a better location.

~modules/darwin~: Darwin-specific modules, including the nix-darwin halves of ~modules/shared~. Pretty barebones because I strongly prefer Linux.

~secrets/~: agenix-encrypted secrets and ~agenix-rules.nix~. Each secret is declared by the module that uses it.

~templates/~: Starting points for new modules; not imported anywhere.

~dots/~: Non-nix dotfiles to copy into an iso file.

~users/~: Defines user accounts

* Building or Deploying
Main workstation:

~nixos-rebuild switch --flake .#wendigo~

Live ISO:

~nixos-rebuild build-image --flake .#live-iso --image-variant iso-installer~

* Backup considerations
+ Container data lives in ~/var/lib/containers/storage/volumes~ and needs to be backed up manually.
+ SSH host keys are in ~/var/lib/ssh~ and need to be backed up manually.
